# РЕСК

Социальная сеть + видеоплатформа + мессенджер для закрытого сообщества.
Тёмная неон-фиолетовая тема, SPA без фреймворков, всё хранится локально — без облака и внешних сервисов.

## Быстрый запуск (Windows)

Двойной клик по **start.bat** — он сам установит зависимости и запустит сервер.

Или в терминале (одна команда):

```
npm install && npm start
```

Откройте в браузере:
- http://localhost:3000  (HTTP)
- https://localhost:3443 (HTTPS, самоподписанный сертификат — браузер попросит подтвердить исключение)

## Первый запуск

Приложение стартует с пустой базой. **Первый зарегистрированный пользователь автоматически получает роль администратора**.

Для разработки можно наполнить сервис тестовыми данными:

```
npm run seed
```

Чтобы вернуться к чистой базе, удалите `space.db` и содержимое `uploads/`.

## Что умеет

- Регистрация, вход, сессии, роли (пользователь / администратор)
- Лента постов: текст + фото/видео, лайки, вложенные комментарии, удаление своих постов
- Видеоплатформа: загрузка, плеер с перемоткой (HTTP Range), просмотры, лайки, комментарии
- Клипы: короткие вертикальные видео
- Мессенджер в реальном времени (Socket.IO) с **сквозным шифрованием (E2EE)** на устройстве
- Профиль: аватар, статус, режим инкогнито, статистика, подписки
- Глобальный поиск по пользователям, постам и видео

## Безопасность

- **2FA (TOTP)** — одноразовые коды + резервные коды; без внешних библиотек (RFC 6238)
- **CSRF** — double-submit cookie + заголовок `X-CSRF-Token` для всех изменяющих запросов
- **Сессии**: access (30 дней) + rotating refresh-токен (60 дней), привязка к IP и User-Agent,
  детект переиспользования токена, список устройств с отзывом
- **Брутфорс**: экспоненциальная блокировка после 5 неудачных попыток + математическая капча
- **Шифрование на диске**: всё содержимое БД и файлов (аватары, фото, видео, превью, бэкапы)
  хранится в зашифрованном виде (AES-256-GCM, мастер-ключ в `.env` — не удаляйте его!)
- **E2EE в чате**: сообщения шифруются в браузере (WebCrypto, ECDH P-256 + AES-GCM),
  сервер хранит только шифротекст; превью в списке чатов — «🔒 Зашифровано»
- **Валидация и санитизация** всех входных данных, параметризованные SQL-запросы
- **Rate limiting** по IP, защитные HTTP-заголовки (CSP, nosniff, HSTS на HTTPS)
- **Журналирование**: действия и тревожные события (входы, смена пароля, подозрительная активность)
- Ссылки по **uid** (base58) вместо числовых ID — защита от перебора

## Резервное копирование

Автоматический зашифрованный бэкап БД каждые 6 часов в `backups/` (хранятся 10 последних).

```
npm run backup          # сделать бэкап сейчас
npm run backup -- list  # список бэкапов
npm run restore -- <файл>  # восстановить БД (только при остановленном сервере!)
```

## Требования

- Node.js 22.5+ (SQLite встроен, ничего ставить не нужно для БД)
- Интернет нужен только один раз для `npm install`

## Структура

```
backend/   — сервер (Express + Socket.IO + node:sqlite)
frontend/  — клиент (index.html + style.css + app.js)
uploads/   — загруженные файлы (аватары, фото, видео, превью) — зашифрованы
backups/   — зашифрованные бэкапы БД
certs/     — самоподписанный TLS-сертификат (генерируется при первом запуске)
space.db   — база данных SQLite (создаётся при первом запуске)
.env       — мастер-ключ шифрования (создаётся при первом запуске, не удаляйте)
```

## Полезное

- Очистить данные: удалите `space.db` и содержимое `uploads/`
- Сменить порт: переменная окружения `PORT` (по умолчанию 3000)
- Проверка после изменений: `npm run smoke` (36 сценариев: авторизация, 2FA, CSRF, E2EE, медиа)

## Android-приложение

Собрано через **Capacitor** (`com.resk.app`). Для подключения к серверу приложение открывает WebView с адресом из `capacitor.config.json` (`server.url`, по умолчанию LAN-адрес ПК). Установочный APK собирается командой:

```
npx cap sync android
cd android && gradlew.bat assembleDebug
```

APK появится в `android/app/build/outputs/apk/debug/app-debug.apk`. Устройство должно быть в той же сети, что и ПК с запущенным сервером.
